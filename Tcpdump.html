什麼是 Tcpdump？

Tcpdump 是一個強大的命令行封包分析工具。如果說 Wireshark 是圖形化的顯微鏡，那 Tcpdump 就是輕量級的瑞士軍刀。

它能「監聽」網卡上流過的所有 0 和 1，並將其翻譯成人類可讀的文字。資安專家常用它在沒有圖形介面的 Linux 伺服器上排查問題或取證。

核心能力：

  • 側錄 (Sniffing)：抓取網卡上的所有流量。
  • 過濾 (Filtering)：只看你想看的（如只看 port 80）。
  • 分析 (Analysis)：查看封包內容（甚至包含明文密碼）。

安裝與啟動

Tcpdump 是幾乎所有 Linux 發行版（包含 Kali）的標配。

# 檢查版本
sudo tcpdump --version

# 列出可用網卡
sudo tcpdump -D

# 最簡單的監聽 (監聽 eth0)
sudo tcpdump -i eth0

實驗需求

  • Kali Linux (Root)
  • 網卡介面: eth0
  • 權限: 必須使用 sudo

常用參數速查

Tcpdump 的參數非常多，這裡列出最常用的幾個：

參數 功能說明
-i [interface] 指定要監聽的網卡（如 eth0, wlan0, any）。
-n 不把 IP 解析成網域名稱（速度較快，顯示 IP）。
-A 以 ASCII (文字) 模式顯示封包內容（抓密碼必用）。
-w [file] 將抓到的封包存成檔案 (.pcap)，供 Wireshark 分析。
host [IP] 只看與特定 IP 有關的流量。
port [80] 只看特定端口的流量。

法律與道德

竊聽是重罪

未經授權攔截他人非公開的通訊內容，違反刑法第 315-1 條 (妨害秘密罪) 與 通訊保障及監察法。

合法使用原則

  • 僅在自己擁有的網路上測試
  • 除錯與故障排除
  • 教學演示環境

資安倫理

不要在公共 WiFi (如咖啡廳) 隨意開啟 Tcpdump。
