什麼是 Aircrack-ng？

Aircrack-ng 不是一個單一的程式，而是一套完整的無線網路安全評估工具組。

它能夠將無線網卡切換到「監聽模式 (Monitor Mode)」，攔截空氣中的 WiFi 封包，並對 WEP、WPA、WPA2 加密進行攻擊與破解。它是每一位想要學習無線安全的駭客必修課。

核心目標：

  • 監聽 (Monitor)：捕獲所有無線流量。
  • 攻擊 (Attack)：斷線攻擊、假基地台。
  • 破解 (Crack)：暴力破解 WiFi 密碼。

安裝與硬體需求

Aircrack-ng 內建於 Kali Linux。但你最需要的是一張支援監聽模式的 USB 無線網卡。

# 安裝 (若未安裝)
sudo apt install aircrack-ng

# 檢查網卡是否支援
iw list

實驗配置

  • 系統: Kali Linux (Root)
  • 網卡: wlan0 (支援 Monitor)
  • 目標: Home_WiFi (WPA2)
  • 字典: rockyou.txt

Aircrack-ng 家族成員

這個套件包含多個工具，各司其職，以下是核心四大金剛：

airmon-ng

配置工具。負責將無線網卡從一般的「管理模式」切換成「監聽模式」，開啟接收所有訊號的能力。

airodump-ng

嗅探工具。負責掃描附近的 WiFi 基地台，顯示頻道、加密方式，並負責抓取握手包 (Handshake)。

aireplay-ng

注入工具。負責主動攻擊，例如發送斷線封包 (Deauth) 強迫使用者斷線，以誘發重新連線。

aircrack-ng

破解工具。不需要網路連線，利用 CPU/GPU 的算力，配合字典檔暴力破解抓到的握手包。

法律與道德

絕對禁止

破解他人的 WiFi 密碼屬於妨害電腦使用罪 (刑法第 358 條)，並可能涉及竊取電信服務罪。

合法使用範圍

  • 測試自己家裡的 WiFi
  • 企業授權的無線安全審計

資安倫理

不要偷連隔壁的 WiFi。
