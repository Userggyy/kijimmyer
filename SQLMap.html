什麼是 SQLMap？

SQLMap 是一款開源的滲透測試工具，專門用來自動化檢測和利用 SQL 注入 (SQL Injection) 漏洞，並接管資料庫伺服器。

它是資料庫滲透領域的「瑞士軍刀」，支援 MySQL, Oracle, PostgreSQL, Microsoft SQL Server 等幾乎多種資料庫。

SQL 注入原理：

當網頁應用程式沒有檢查使用者輸入的內容，駭客可以在輸入框（或網址參數）中插入惡意的 SQL 指令，騙過資料庫執行，從而竊取資料或繞過登入。

安裝與啟動

SQLMap 是 Python 編寫的工具，內建於 Kali Linux。

# 安裝 (若未安裝)
sudo apt install sqlmap

# 更新到最新版
sudo sqlmap --update

# 檢查版本
sqlmap --version

實驗配置

  • 攻擊機: Kali Linux
  • 靶機: testphp.vulnweb.com
  • 參數: id=1 (注入點)

攻擊流程參數

SQLMap 的參數設計非常有邏輯，通常是從外到內一層層剝開：

參數 功能說明
-u "URL" 指定目標網址 (Target URL)。
--dbs 列出所有資料庫名稱 (Databases)。
-D [db] 指定要攻擊的資料庫名稱。
--tables 列出指定資料庫中的資料表 (Tables)。
-T [table] 指定要攻擊的資料表名稱。
--columns 列出指定資料表中的欄位 (Columns)。
--dump 脫庫。將指定內容全部下載並顯示出來。

法律與道德

絕對禁止

未經授權對網站進行 SQL 注入測試是嚴重犯罪，違反刑法第 358 條，且可能導致資料庫損毀。

合法練習平台

  • DVWA (Damn Vulnerable Web App)
  • OWASP Juice Shop
  • VulnHub 靶機

資安倫理

請愛護資料庫，不要隨意 Drop Table。
