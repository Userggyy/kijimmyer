Masscan 是什麼？

Masscan 是目前世界上最快的網際網路端口掃描器。它採用非同步傳輸（Asynchronous transmission）技術，類似於 scanrand、unicornscan，但速度更快。

Masscan vs Nmap

特性 Masscan Nmap
掃描速度 極快 (每秒 1000萬+ 封包) 較慢 (適合精細掃描)
主要用途 大規模 IP 範圍偵查 單一主機深層漏洞檢測
準確度 較低 (可能會漏包) 極高 (三向交握完整)

安裝與使用

Masscan 需要 Root 權限 才能發送原始封包。在 Kali Linux 中通常已預裝。

# 1. 安裝 Masscan
sudo apt-get install masscan

# 2. 查詢網卡名稱 (重要!)
ip addr

# 3. 基礎語法
sudo masscan -p80,443 192.168.1.0/24 --rate=1000

實驗需求

  • Kali Linux (Root)
  • 目標網段: 192.168.1.0/24
  • 必須使用 sudo

理解輸出結果

Masscan 的輸出非常直觀，它只會告訴你發現了什麼（Discovered），而不會告訴你什麼沒發現。

標準輸出範例：

Discovered open port 80/tcp on 192.168.1.150
Discovered open port 22/tcp on 192.168.1.150
Discovered open port 443/tcp on 192.168.1.100

為什麼要用 --rate?

這是 Masscan 的核心。如果不設定速率，它可能會試圖以網卡的極限速度發送封包（每秒百萬級），這會導致：

  • 家用路由器當機：大多數路由器無法處理這麼多並發連線。
  • 被防火牆封鎖：極高頻率的掃描會立刻觸發 IDS/IPS。
  • 自身網路癱瘓：你的網路頻寬會被佔滿，無法上網。

法律與道德

特別警告

Masscan 的攻擊性比 Nmap 更強！因為它會瞬間產生大量流量，極易被視為 DoS 攻擊。

合法使用範圍

  • 掃描自己擁有的 IP 範圍
  • 完全隔離的虛擬機內網
  • 嚴禁掃描網際網路
