什麼是 Wifite？

Wifite 是一款 Python 編寫的自動化無線滲透測試工具。它的設計理念是：「讓 WiFi 破解變得像呼吸一樣簡單」。

相比於 Aircrack-ng 需要手動執行每一個步驟（開啟監聽、掃描、抓包、破解），Wifite 將這些繁瑣的過程全部自動化。你只需要選擇目標，剩下的工作它全包了。

為什麼選它？

  • 全自動流程：自動開啟 Monitor Mode，自動掃描。
  • 多重攻擊向量：自動嘗試 WPS (Pixie Dust)、WPA (Handshake)、PMKID 攻擊。
  • 去複雜化：不需要記住複雜的參數。

安裝與啟動

Wifite 內建於 Kali Linux，但建議使用最新版 (v2) 以支援 PMKID 攻擊。

# 安裝
sudo apt install wifite

# 啟動 (需要 root)
sudo wifite

# 強力模式 (殺死干擾進程)
sudo wifite --kill

實驗配置

  • 系統: Kali Linux
  • 網卡: wlan0 (Monitor)
  • 目標: Home_WiFi
  • 模式: Auto Attack

自動化攻擊策略

Wifite 之所以強大，是因為它會依序嘗試以下策略，直到成功為止：

PMKID 攻擊

針對 WPA2 的新式攻擊。不需要使用者在線，直接與路由器溝通即可抓取雜湊值。這是 Wifite 的首選。

WPA 握手包

傳統攻擊。Wifite 會自動發送斷線封包 (Deauth)，強迫使用者重連，藉此抓取 Handshake。

WPS Pixie Dust

針對 WPS 的離線暴力破解。如果路由器有漏洞，幾秒鐘內就能算出 PIN 碼和密碼。

自動破解

抓到包後，Wifite 會自動呼叫 Aircrack-ng 並載入字典檔 (wordlist) 進行破解，完全不需人工介入。

法律與道德

腳本小子的陷阱

自動化工具很容易讓人「誤觸法網」。Wifite 預設會攻擊所有目標 (--all)，若不小心攻擊到鄰居或公共網路，即構成刑事犯罪。

安全建議

  • 務必指定單一目標 (-b 或選單選擇)
  • 不要在公共場所執行

資安倫理
