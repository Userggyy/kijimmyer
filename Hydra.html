什麼是 Hydra？

THC-Hydra 是一個快速且支援多種協定的網路登入破解工具。它使用「暴力破解 (Brute Force)」或「字典攻擊 (Dictionary Attack)」的方式，嘗試猜解目標的帳號與密碼。

它支援 SSH, FTP, HTTP, SMB, RDP, MySQL 等超過 50 種服務，是滲透測試中不可或缺的重型武器。

攻擊模式：

  • 字典攻擊：使用預先準備好的「常見密碼表」(如 rockyou.txt) 進行嘗試，效率較高。
  • 暴力破解：嘗試所有可能的字元組合 (aaaa, aaab...)，耗時極長但理論上必能破解。

安裝與準備

Hydra 內建於 Kali Linux。你需要準備的是「字典檔 (Wordlists)」。

# 安裝 (若未安裝)
sudo apt install hydra

# 準備字典檔 (Kali 內建)
/usr/share/wordlists/rockyou.txt

# 基礎語法
hydra -l user -P passlist.txt [IP] [Service]

實驗配置

  • 攻擊機: Kali Linux
  • 目標: 192.168.1.150
  • 字典: rockyou.txt
  • 服務: SSH / FTP

關鍵參數解析

Hydra 的參數區分大小寫，這點非常重要！

參數 功能說明
-l [user] 小寫 l：指定單一帳號 (如 -l admin)。
-L [file] 大寫 L：指定帳號清單 (List of users)。
-p [pass] 小寫 p：指定單一密碼 (很少用，除非測試)。
-P [file] 大寫 P：指定密碼字典 (Password list)。
-t [num] 執行緒 (Threads)，決定同時嘗試的數量，預設 16。
-v / -V 顯示詳細過程 / 顯示每一個嘗試的帳密組合。

法律與道德

嚴重警告

對未經授權的主機進行暴力破解是非法行為。即使沒猜中密碼，大量的登入失敗紀錄也會被系統管理員發現並視為攻擊。

合法使用範圍

  • 測試自己架設的伺服器
  • 檢測企業員工是否使用弱密碼
  • CTF 練習

防禦建議

使用強密碼 • 限制登入次數 (Fail2Ban)
