什麼是 Hping3？

如果說 Nmap 是全自動步槍，Hping3 就是一把精準的手術刀。它是一個命令行導向的封包組合與分析工具，允許你「手工打造」TCP、IP、UDP 或 ICMP 封包。

為什麼需要它？

  • 防火牆測試：測試防火牆是否真的擋住了特定封包（如 FIN 或 NULL）。
  • 進階掃描：當標準 Ping (ICMP) 被封鎖時，用 TCP ACK 來探測主機。
  • 網路壓力測試：可以自訂發送頻率來測試伺服器抗壓性。

安裝與基礎語法

# 1. 安裝 (Kali 內建)
sudo apt install hping3

# 2. 基礎語法
# hping3 [參數] [目標IP]
sudo hping3 -S -p 80 192.168.1.150

注意： Hping3 需要 root 權限才能構造原始封包 (Raw Socket)。

實驗需求

  • Kali Linux (Root)

讀懂 TCP Flags (暗號解析)

Hping3 的回傳結果中最重要的是 flags=...，這代表伺服器對你的封包做出了什麼反應。

標記 全名 含義與白話解釋
SA SYN + ACK Port 是開的 (Open)
伺服器說：「我收到你的連線請求(SYN)了，我同意(ACK)。」
RA RST + ACK Port 是關的 (Closed)
伺服器說：「這裡沒有服務，重置連線(RST)，請滾。」
A ACK 回應確認
通常用於 Ping 回應，表示主機活著。
(無) (Timeout) 被過濾 (Filtered)
完全沒有回應，通常是被防火牆丟棄了封包。

法律與道德

禁止 DoS 攻擊

Hping3 的 --flood 功能極其危險，對未經授權的目標使用此功能構成阻斷服務攻擊 (DoS)，是嚴重犯罪行為。

合法使用範圍

  • 防火牆規則測試
  • 自有網路壓力測試
  • TCP/IP 協議研究
