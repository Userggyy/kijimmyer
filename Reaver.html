什麼是 Reaver？

Reaver 是一款專門針對 **WPS (Wi-Fi Protected Setup)** 漏洞的攻擊工具。WPS 原本是為了讓使用者方便連線（按一下按鈕就好），但它設計上的缺陷讓它成為了駭客眼中的超級後門。

即使你的 WiFi 密碼設定了 63 位亂碼，只要 WPS 功能開啟，Reaver 就能透過嘗試 8 位數的 PIN 碼，在數小時內破解並取得你的 WiFi 密碼。

WPS 的致命缺陷：

  • 分段驗證：8 位數 PIN 碼被分成前半段 (4位) 和後半段 (3位+檢查碼) 分開驗證。
  • 組合數極少：原本需要猜 1 億次 (10^8)，因為分段驗證，只需要猜 11,000 次 (10^4 + 10^3)。

安裝與需求

Reaver 內建於 Kali Linux。你需要一張支援監聽模式 (Monitor Mode) 的網卡。

# 安裝 (若未安裝)
sudo apt install reaver

# 配合使用的 wash (掃描 WPS)
sudo apt install wash

實驗配置

  • 系統: Kali Linux (Root)
  • 網卡: wlan0mon
  • 目標: Target_AP (WPS On)
  • 攻擊: Pixie Dust / Brute

為什麼 WPS 這麼容易破？

WPS 的 PIN 碼驗證機制設計上有個天大的漏洞：

驗證階段 PIN 碼長度 可能性 (組合數)
前半段 (M4) 4 位數 10,000 種
後半段 (M6) 3 位數 (最後1位是檢查碼) 1,000 種
總計 8 位數 11,000 種 (極少!)

如果沒有這個漏洞，破解 8 位數需要嘗試 1 億次；但因為路由器會「分別告訴你」前半段對不對、後半段對不對，導致難度瞬間降低了 99.99%。

法律與道德

違法警告

未經授權破解他人 WiFi，即使只是測試，也違反刑法第 358 條 (無故入侵電腦) 及 電信法。

防禦建議

  • 關閉 WPS 功能 (最有效)
  • 使用最新 WPA3 加密
  • 啟用 MAC 過濾 (較弱)
