什麼是 Tshark？

Tshark 是全球最流行的封包分析軟體 Wireshark 的命令行 (CLI) 版本。如果說 Tcpdump 是快速的攔截工具，Tshark 就是精密的「封包解剖師」。

它擁有與 Wireshark 相同的強大解碼引擎，可以識別數千種協定，並且能將封包內的細微欄位（如 User-Agent、DNS Query）精準提取出來。

Tshark vs Tcpdump：

  • Tcpdump：擅長「抓」。輕量、快速、適合看表層資訊。
  • Tshark：擅長「解」。能讀懂封包內容，適合做統計、過濾特定欄位。

安裝與啟動

Tshark 通常包含在 Wireshark 套件中。在 Kali Linux 是預裝的。

# 安裝 (Debian/Ubuntu)
sudo apt install tshark

# 檢查版本
tshark -v

# 互動模式 (類似 Wireshark 的文字版)
tshark

實驗需求

  • Kali Linux (Root)
  • 範例檔案: traffic.pcap
  • 學習 Display Filter

常用參數速查

Tshark 的參數比 Tcpdump 複雜，但功能更強大。記得 Tshark 使用的是 Wireshark 的過濾語法。

參數 功能說明
-r [file] 讀取 (Read) 封包檔案 (.pcap)。
-Y [filter] 顯示過濾器 (Display Filter)。例如 http 或 ip.addr==1.1.1.1。
-T fields 指定輸出格式為「欄位」。配合 -e 使用。
-e [field] 提取特定欄位。如 -e ip.src (來源IP)、-e http.host (網址)。
-z [stats] 執行統計功能。如 -z io,phs (Protocol Hierarchy Statistics)。

法律與道德

隱私紅線

使用 Tshark 深度解析他人通訊內容（如提取 Cookies、對話紀錄），違反刑法第 315-1 條。

合法使用原則

  • 企業內部的惡意流量分析
  • CTF 資安競賽
  • 自身程式的除錯

資安倫理

分析是為了防禦，不是為了窺探。
