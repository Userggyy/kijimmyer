什麼是 SQLNinja？

SQLNinja 是一款專門針對 Microsoft SQL Server 的滲透測試工具。它與 SQLMap 最大的不同在於目標：SQLMap 擅長「脫庫（偷資料）」，而 SQLNinja 擅長**「奪權（取得 Shell）」**。

如果網頁應用程式使用高權限的資料庫帳號（如 `sa`）連接 MSSQL，SQLNinja 可以利用注入漏洞開啟 `xp_cmdshell`，進而執行作業系統指令，甚至開啟 VNC 遠端桌面。

適用情境：

  • 目標資料庫是 Microsoft SQL Server (2000/2005/2008/2012...)。
  • 目標可能位於防火牆後，需要反向連接 (Reverse Shell)。
  • 目標是 Windows Server 環境。

安裝與設定

SQLNinja 是用 Perl 編寫的，內建於 Kali Linux。它的操作高度依賴設定檔。

# 安裝 (若未安裝)
sudo apt install sqlninja

# 編輯設定檔 (這是關鍵步驟!)
vim /etc/sqlninja.conf

# 啟動工具
sqlninja -m <mode> -f <config_file>

實驗配置

  • 攻擊機: Kali Linux
  • 靶機: Windows Server 2012
  • DB: SQL Server (sa user)
  • 目標: Get Shell / VNC

SQLNinja 攻擊模式 (-m)

SQLNinja 的功能透過 -m 參數切換，以下是幾個關鍵模式：

模式代號 功能說明
test (t) 連線測試
確認注入點是否有效，以及是否能與目標溝通。
fingerprint (f) 指紋識別
偵測 SQL Server 版本、使用者權限 (sa/dbo)。
bruteforce (b) 暴力破解
如果當前權限不夠，嘗試猜解 sa 帳號密碼。
escalation (e) 權限提升
啟用 xp_cmdshell，這是執行系統指令的關鍵。
upload (u) 上傳執行
利用 debug.exe 或 vbs 將木馬 (nc.exe, VNC) 傳入目標並執行。

法律與道德

嚴重警告

使用 SQLNinja 取得系統 Shell 或 VNC 權限，屬於非法控制電腦系統，違反刑法第 358、359 條，刑責極重。

防禦建議

  • 不要使用 sa 帳號連線網頁
  • 停用 xp_cmdshell
  • 更新 SQL Server 補丁
