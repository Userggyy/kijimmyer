什麼是 SET？

Social-Engineer Toolkit (SET) 是一個專門針對「人性弱點」進行攻擊的開源滲透測試框架。

不同於 Metasploit 攻擊系統漏洞，SET 主要用於攻擊「人」。它可以快速生成釣魚網站、偽造電子郵件、或是帶有惡意 Payload 的 QR Code，用來測試企業員工的資安意識。

為什麼這很危險？

再強大的防火牆也擋不住一個自願交出密碼的員工。社交工程 (Social Engineering) 往往是駭客入侵企業內網的第一步。

安裝與啟動

SET 內建於 Kali Linux。它的操作介面是互動式選單，不需要背誦複雜參數。

# 安裝 (若未安裝)
sudo apt install set

# 啟動工具 (需要 root)
sudo setoolkit

實驗配置

  • 攻擊機: Kali Linux
  • 偽造目標: Gmail / FB
  • 攻擊方式: 憑證收割
  • 監聽 Port: 80

常見攻擊向量

SET 提供了多種攻擊手法，以下是選單中最常用的幾個：

攻擊名稱 原理與說明
Spear-Phishing 魚叉式釣魚。發送帶有惡意附件（如 PDF、Word）的 Email 給特定目標。
Website Vectors 網站攻擊。包含 Java Applet 攻擊、網站複製、憑證竊取。
Credential Harvester 憑證收割機。複製一個像 Gmail 或公司登入頁面的網站，誘騙使用者輸入帳密。
QRCode Generator 產生一個指向惡意網站的 QR Code，貼在實體世界讓人掃描。

法律與道德

詐欺與偽造

製作釣魚網站竊取他人帳號，違反刑法第 339-4 條 (加重詐欺罪) 及 358 條 (妨害電腦使用)。

合法使用原則
