什麼是 SET？

Social-Engineer Toolkit (SET) 是一個專門針對「人性弱點」進行攻擊的開源滲透測試框架。

不同於 Metasploit 攻擊系統漏洞，SET 主要用於攻擊「人」。它可以快速生成釣魚網站、偽造電子郵件、或是帶有惡意 Payload 的 QR Code。

為什麼這很危險？

再強大的防火牆也擋不住一個自願交出密碼的員工。社交工程 (Social Engineering) 往往是駭客入侵企業內網的第一步。

安裝與啟動

SET 內建於 Kali Linux。它的操作介面是互動式選單，不需要背誦複雜參數。

# 安裝 (若未安裝)
sudo apt install set

# 啟動工具 (需要 root)
sudo setoolkit

實驗配置

  • 攻擊機: Kali Linux
  • 偽造目標: Gmail / FB
  • 攻擊方式: 憑證收割
  • 監聽 Port: 80

防禦與預防措施

了解攻擊是為了更好的防禦。針對上述的攻擊手法，我們應採取以下防護措施：

針對攻擊 (Defense Against) 防護建議 (Best Practice)
魚叉式釣魚
Spear-Phishing		 確認寄件者身分，不隨意開啟不明附件 (PDF/Word)。若收到緊急要求的信件，請透過其他管道（如電話）查證
網站攻擊 / 釣魚
Website Vectors		 檢查網址 (URL) 正確性，確認 HTTPS 憑證是否為偽造。不要在來源不明的視窗中輸入敏感資料
憑證收割機
Credential Harvester		 啟用雙重認證 (2FA/MFA)。這是對抗帳號竊取最有效的方法，即使密碼外洩，駭客沒有手機驗證碼也無法登入
惡意程式 / QR Code
Payloads		 保持作業系統與防毒軟體更新。掃描實體 QR Code 前請確認來源，避免掃描路邊不明的條碼
