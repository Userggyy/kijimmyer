什麼是 Searchsploit？

Searchsploit 是 Exploit-DB 的官方命令列搜尋工具。當我們透過 Nmap 或其他掃描工具發現目標主機的服務版本後（例如 Apache 2.4.49），最關鍵的一步就是確認「這個版本是否有已知的安全漏洞」。

Searchsploit 就是這個環節的絕對主角。它內建了成千上萬個已公開的漏洞利用代碼 (Exploits)，而且完全離線。它能將單純的「版本資訊」轉化為致命的「攻擊情報」。

核心價值：

Nmap 負責告訴你「門在哪裡」，而 Searchsploit 負責告訴你「哪把鑰匙能開這扇門」。

偵查 (Nmap) 精確鎖定 (Searchsploit)

安裝與更新

Searchsploit 內建於 Kali Linux。保持資料庫最新是非常重要的。

# 安裝 (若未安裝)
sudo apt install exploitdb

# 更新漏洞資料庫
searchsploit -u

實用技巧

Searchsploit 的功能不只是關鍵字搜尋：

  • 精確搜尋 (Strict Search)
    searchsploit -s "Apache 2.4"
    如果你不想看到 "Apache 1.x" 的結果，使用 -s 進行精確匹配。
  • 排除特定詞 (Exclude)
    searchsploit apache --exclude="DoS"
    排除那些只能造成當機 (DoS) 的腳本，專注於能拿到權限 (RCE) 的漏洞。
  • 檢視腳本 (Examine)
    searchsploit -x 12345.py
    直接在終端機開啟並閱讀腳本內容，不用複製出來。

法律與道德

惡意後門警示

下載並執行網路上不明來源的 Exploit 腳本是非常危險的。有些腳本可能包含惡意後門，反過來攻擊你的電腦。

安全守則

  • 永遠先閱讀代碼：不要直接執行。
  • 在沙盒中測試：先在虛擬機測試效果。
  • 確認授權：只對授權目標使用。
