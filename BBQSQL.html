什麼是 BBQSQL？

BBQSQL 是一款用 Python 編寫的輕量級、參數化盲注（Blind SQL Injection）工具。當 SQLMap 因為網站防火牆 (WAF) 或複雜的資料庫結構而失效時，BBQSQL 是資安專家的最後手段。

它的特點是「半自動」：你需要告訴它注入點在哪裡，但一旦設定好，它的猜解速度（利用二分法）非常驚人。

什麼是盲注 (Blind Injection)？

就像玩「20 個問題」猜謎遊戲。你問資料庫：「密碼第一個字是 A 嗎？」，資料庫只會回答「對」或「錯」（通過頁面回應差異），駭客就這樣一個字一個字把資料「問」出來。

安裝與啟動

BBQSQL 內建於 Kali Linux，也可以透過 pip 安裝。

# 安裝 (Python 2 環境)
pip install bbqsql

# 啟動工具
bbqsql

實驗配置

  • 系統: Kali Linux
  • 靶機: vulnerable_app
  • 漏洞: Blind SQLi

BBQSQL 強大之處

為什麼在有 SQLMap 的情況下還需要 BBQSQL？

特點 說明
Semi-Automatic 半自動化
允許使用者精確控制每一個參數，適合處理非標準的注入場景。
Binary Search 二分法搜尋
比如猜數字 1-100。它不會問「是1嗎？」，而是問「大於50嗎？」。速度極快。
Hooks 自定義鉤子
可以在發送請求前或後執行 Python 腳本，用來繞過登入驗證或處理 Hash。
Concurrency 高併發
使用 Gevent 協程技術，發送請求的速度極快。

法律與道德

違法警告

盲注攻擊會產生大量異常流量，極易被 WAF 偵測並封鎖 IP。未經授權測試同樣違反刑法第 358 條。

防禦建議

  • 使用參數化查詢 (Prepared Statements)
  • 關閉詳細錯誤訊息
  • 使用 WAF 阻擋 SQL 關鍵字
