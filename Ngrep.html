什麼是 Ngrep？

Ngrep (Network Grep) 是網路版的 grep 工具。如果你熟悉在 Linux 檔案中搜尋文字的 grep 指令，那你一定會愛上 Ngrep。

不同於 Tcpdump (看標頭) 或 Tshark (看結構)，Ngrep 的專長是「暴力搜尋封包內容 (Payload)」。它允許你使用正則表達式 (Regex) 來過濾封包的數據部分，是抓取帳密、特定網址或惡意特徵碼的神器。

為什麼選它？

  • 直覺：想找 "password"？直接打 `ngrep 'password'` 就好。
  • 可讀性：支援 -W byline，自動把 HTTP 封包排版成易讀格式。
  • 輕量：專注於內容匹配，沒有複雜的解碼負擔。

安裝與啟動

Ngrep 在 Kali Linux 中通常已預裝。它同樣需要 Root 權限來監聽網卡。

# 安裝 (Debian/Ubuntu)
sudo apt install ngrep

# 檢查版本
ngrep -V

# 最簡單的用法 (監聽 eth0，搜尋 'GET' 關鍵字)
sudo ngrep -d eth0 'GET'

實驗需求

  • Kali Linux (Root)
  • HTTP 流量 (明文)
  • 關鍵字概念 (Regex)

常用參數速查

Ngrep 的語法結構為：ngrep [參數] '關鍵字' [BPF過濾條件]

參數 功能說明
-q 安靜模式 (Quiet)。只顯示匹配到的封包內容，不顯示雜七雜八的標頭符號（如 ######）。
-W byline 換行顯示。這是 Ngrep 最重要的參數！它會把封包內容依照換行符號排版，閱讀 HTTP 必備。
-d [dev] 指定網卡介面 (Device)，如 eth0, any。
-i 忽略大小寫 (Ignore case)。搜尋 'pass' 也會找到 'PASS'。
-x 以 16 進位 (Hex) 格式顯示封包內容。

法律與道德

隱私紅線

使用 Ngrep 搜尋敏感關鍵字（如 password, cookie）涉及深度封包檢測，未經授權使用違反刑法第 315-1 條。

合法使用原則

  • 網站開發除錯 (Debug)
  • API 流量分析
  • CTF 競賽解題
