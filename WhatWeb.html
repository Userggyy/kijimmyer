什麼是 WhatWeb？

WhatWeb 是一款強大的網站指紋識別工具。它就像是網站的「X 光機」，只要輸入一個網址，它就能分析出該網站使用了哪些技術。

它能識別內容管理系統 (CMS)、部落格平台、統計分析套件、JavaScript 函式庫、網頁伺服器版本，甚至能抓出電子郵件地址和 SQL 錯誤訊息。

為什麼需要指紋識別？

在攻擊之前，我們必須知道目標「長什麼樣子」。如果知道目標使用 WordPress 4.9，駭客就不會浪費時間去測試針對 Joomla 的攻擊腳本。

知己知彼，百戰不殆。

安裝與啟動

WhatWeb 是 Kali Linux 的標配工具，開箱即用。

# 基礎掃描
whatweb example.com

# 查看詳細資訊 (Verbose)
whatweb -v example.com

常用參數指令

參數 功能說明
-v / --verbose 詳細模式，顯示每一個外掛 (Plugin) 的詳細描述，而不只是單行摘要。
-a [level] 掃描強度 (Aggression)
1: 隱密 (Stealthy)
3: 積極 (Aggressive) - 會發送較多請求以觸發回應。
4: 重型 (Heavy) - 嘗試所有可能。
--log-json=[file] 將結果輸出為 JSON 格式，方便後續用 Python 腳本處理。
--list-plugins 列出所有支援的指紋外掛（目前超過 1800 種）。

法律與道德

隱私邊界

WhatWeb 的積極掃描模式 (-a 3 or 4) 會向伺服器發送大量特定的 HTTP 請求，這會在伺服器日誌中留下明顯痕跡，甚至觸發 IDS/IPS 警報。

操作守則

  • 不要對未授權目標使用積極掃描。
  • 尊重 Robots.txt：雖然駭客通常不遵守，但這是禮貌。

資安倫理

你的每一個請求都會留下足跡。
